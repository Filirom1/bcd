# Gérer les classes

Cette page te permet de consulter et gérer les classes de l'école.

---

## Étape 1 — Consulter la liste des classes

La page affiche toutes les classes de l'école avec le nombre d'élèves par classe.
Clique sur une classe pour voir la liste de ses élèves.

![Liste des classes avec le nombre d'élèves](../images/classes-01-list.png)

> **Conseil :** Les classes sont triées par niveau (CP, CE1, CE2, CM1, CM2). Tu peux modifier l'ordre dans les paramètres.

## Étape 2 — Créer une nouvelle classe

Clique sur « Créer une classe » en haut à droite.
Renseigne le nom de la classe et le niveau.

> **Conseil :** En début d'année scolaire, crée d'abord toutes les classes, puis importe les élèves avec leur classe dans la page Emprunteurs.

## Étape 3 — Modifier ou supprimer une classe

Clique sur le bouton « Modifier » à côté d'une classe pour changer son nom.
Le bouton « Supprimer » est disponible uniquement si la classe n'a plus d'élèves.

---

## Problèmes fréquents

| Problème | Solution |
|----------|----------|
| Impossible de supprimer une classe | Une classe avec des élèves ne peut pas être supprimée. Déplace d'abord les élèves vers une autre classe. |
| Les élèves n'apparaissent pas dans la classe | L'élève n'est peut-être pas assigné à cette classe. Vérifie sa fiche dans la page Emprunteurs. |
| Le nombre d'élèves ne correspond pas | Actualise la page — le compteur se met à jour après chaque import ou modification. |
