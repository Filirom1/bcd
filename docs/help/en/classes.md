# Managing classes

View and manage school classes to organize borrowers.

---

## Step 1 — View the class list

The page displays all school classes with the number of students per class.
Click on a class to see the list of its students.

![Class list with student count](../images/classes-01-list.png)

> **Tip:** Classes are sorted by grade level (Year 1–5). You can change the order in Settings.

## Step 2 — Create a new class

Click "Create a class" in the top right.
Enter the class name and grade level.

> **Tip:** At the start of the school year, create all classes first, then import students with their class in the Borrowers page.

## Step 3 — Edit or delete a class

Click the "Edit" button next to a class to change its name.
The "Delete" button is only available if the class has no students.

---

## Common Issues

| Problem | Solution |
|---------|----------|
| Cannot delete a class | A class with students cannot be deleted. Move the students to another class first. |
| Students do not appear in the class | The student may not be assigned to this class. Check their record in the Borrowers page. |
| Student count does not match | Refresh the page — the counter updates after each import or modification. |
