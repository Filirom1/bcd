# BCD Kids — Teacher's Guide

## What is it?

**BCD Kids** lets your students borrow, return, search and reserve library books **on their own**, without needing your help.

The app runs on the library computer (or any computer connected to the school network). In a few taps, a student can manage their loans independently.

---

## First Launch

> Do this **once** at setup.

1. Make sure the **BCD server is running** on the main computer
2. Double-click the **BCD Kids** icon on the desktop
3. The app searches for the server automatically — wait a few seconds
4. Once connected, adjust the **display settings** for your screen (see [Settings](#settings-️))

> 💡 If the connection fails, see [Troubleshooting](#troubleshooting).

---

## What Students See — Step by Step

### 1 — Choose a class
A grid shows all classes. The student taps their class.

### 2 — Enter a first name
The student types the first few letters of their name. A list of matches appears. If several students share the same name, they pick their full name from the list.

> ⚠️ If **"First name not found in this class"** appears, the student is probably not yet registered in their class in the library software. Contact the library manager.

### 3 — Personal menu
The student sees their current loans and can access all features:

| Button | What it does |
|---|---|
| 📖 BORROW A BOOK | Scan a book's barcode to borrow it |
| 🔍 SEARCH FOR A BOOK | Search by title, author or genre |
| 📌 MY HOLDS | View and cancel reservations |
| ✅ RETURN BY SCAN | Return a book by scanning its barcode |

### 4 — Borrowing a book
The student scans the barcode. The loan is confirmed immediately. They can scan several books in a row without leaving the screen.

### 5 — Searching and reserving
The student searches for a book. If it is **already on loan**, a **Reserve** button appears. After confirming, the student returns automatically to their personal menu. Reserved books appear highlighted in the **reservation colour** if they search again.

## Your Role as a Teacher

### Managing ready holds

When a student returns a book that is **reserved by another student**, the app automatically shows a **yellow screen** with:
- the book title
- the waiting student's name
- their class

**Your action:** set the book aside and let the student know it is ready.

### Quick returns

From the class selection screen, you can scan a book barcode directly to return it **without going through a student account**. Useful for processing returns quickly at the start of the day.

| Option | When to use |

## Frequently Asked Questions

**A student can't find their name**
They must type at least 2 letters. If "First name not found in this class" still appears, the student is not registered in that class in the library software. Check with the library manager.

**A student has reached their borrowing limit**
The app tells them clearly. They must return a book before borrowing another.

**A student wants to reserve a book that is on loan**
They search for it, then tap **Reserve**. The reservation is saved and they return to their menu.

**How do I switch to a different library server?**
Tap the button showing the library name (top left of the class selection screen). This takes you back to the connection screen.

**A student is stuck in the app**
The **← Back** button is available on every screen. As a last resort, close and relaunch the app.

## Troubleshooting

| Problem | Solution |
|---|---|
| App can't find the server | Check that the BCD server is running. Try manual connection (see below). |
| Image looks pixelated | ⚙️ → Quality **High** |
| App is slow or freezes | ⚙️ → Quality **Low**, resolution **1280×720** |
| Barcode scanner not responding | Check it is plugged in. Relaunch the app. |
| A student's name never appears | The student is not registered in their class in the library software. |
| Screen is frozen | Close and relaunch BCD Kids. |

### Manual connection

If automatic connection fails:
1. On the connection screen, fill in the **"Or type your library's address"** field
2. Enter the address provided by your IT support, e.g. `http://192.168.1.100:8000`
3. Click **Connect**

> 💡 If you don't have the address, contact your school's IT support.
